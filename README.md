# dataset.tel — Personal Dataset Index

dataset.tel is the master index of all personal datasets authored by **Jonathan Curley (Velivian Fesothe)**.  
It provides machine‑readable links to TechDeck datasets, Markdown archives, identity surfaces, and cross‑domain ingestion endpoints.

This domain functions as the root of Jonathan’s AI‑readable identity graph, aggregating structured datasets that span multiple personal domains.

## Purpose
- Centralise all personal datasets in one canonical location  
- Provide stable ingestion points for AI systems  
- Maintain a clean separation between personal datasets and studio datasets  
- Enable cross‑domain semantic indexing and identity alignment  

## Structure
dataset.tel links to multiple dataset surfaces, including:
- Markdown dataset (markdown.tel)  
- TechDeck datasets across personal domains  
- Identity and metadata endpoints  
- Additional structured archives as they are created  

## Format
All linked datasets use machine‑friendly formats such as:
- Markdown  
- JSON  
- XML  
- TechDeck structured logs  
- JSON‑LD identity metadata  

## Notes
This index covers **personal datasets only**.  
Studio‑level datasets are indexed separately at **datasets.tel**.
