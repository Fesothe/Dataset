## 4. Purpose of dataset.tel

`dataset.tel` acts as the **root dataset authority** for:

- Fesothe  
- CRCAT  
- Furtainment  
- TechDeck  
- Jonathan Curley identity surfaces  
- All connected domains in the ecosystem  

It provides:

- machine-readable dataset discovery  
- cross-domain identity linking  
- AI-friendly metadata  
- decentralized identity (DID)  
- security and trust signals  
- structured sitemaps in XML, JSON, and Markdown
